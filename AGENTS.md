# Regras de entrega do projeto

- Toda alteração concluída neste projeto deve ser versionada e enviada ao repositório GitHub remoto.
- A publicação online deve permanecer sincronizada com a branch principal.
- Antes da entrega, aguarde o deploy automático do Cloudflare e valide a versão publicada.
- Não considere uma alteração entregue somente porque funciona no ambiente local.
